\section{Implementácia priamej a inverznej kinematiky manipulátora}

Riešenie vychádza z pôvodných pseudokódov, ktoré boli prenesené do programovej formy pre 6-stupňový manipulátor v C++ pod knižnicou Eigen.

Kinematický model je definovaný pomocou:
\begin{itemize}
	\item sekvencie rotácií jednotlivých kĺbov,
	\item translačných vektorov medzi kĺbmi podľa mechanickej konštrukcie.
\end{itemize}

\subsection{Priama kinematika}
Slúži na výpočet polohy a orientácie efektora zo známych kĺbových uhlov.

Výstupom je:
\begin{itemize}
	\item polohový vektor efektora $p \in \mathbb{R}^3$,
	\item rotačná matica efektora $R \in \mathbb{R}^{3 \times 3}$.
\end{itemize}

\subsubsection{Pseudokód pre priamu kinematiku}
Nižšie je uvedený pseudo program na výpočet priamej kinematickej úlohy, ktorý zohľadňuje všetky články manipulátora a ich vzájomné transformácie.
Čiže pseudo program vracia polohový vektor a rotačnú maticu koncového efektora vzhľadom na základňu manipulátora.

\begin{lstlisting}[caption={Výpočet priamej kinematickej úlohy}, language=C]
function forwardKinematics(theta[], R[])
    vekt = 0;
    matica = I_3x3;
    n = size(theta[]);
    
    for (i = n; i > 0; i--) begin
        vekt = R[i](theta[i]) * (T[i] + vekt);
        matica = R[i](theta[i]) * matica;
    end
    
    return vekt, matica;
end function
\end{lstlisting}

Poloha je počítaná rekurzívne od konca članka smerom k základni. Orientácia efektora vzniká ako súčin rotačných matíc všetkých kĺbov v poradí od základne po efektor.

\subsection{Inverzná kinematika}

Hľadá požadované kĺbové uhly iteratívnou Newtonovou metódou. Cieľom je nájsť také kĺbové uhly, aby efektor dosiahol požadovanú polohu a orientáciu.

\begin{itemize}
	\item \textbf{Výpočet chyby:} V každom kroku sa určuje polohová a orientačná chyba (reziduum) oproti požadovanému stavu.
	\item \textbf{Riešenie sústavy:} Zmena kĺbových uhlov sa počítá cez úplný Jakobián riešením lineárnej sústavy $J\Delta\theta = -r$, kde $r$ je spojený vektor chýb.
	\item \textbf{Regularizácia:} Na zabezpečenie numerickej stability pri horšej podmienenosti Jakobiánu a v singularitách sa používa tlmiací parameter $\lambda$.
	\item \textbf{Normalizácia:} Po každej iterácii sa vypočítané uhly zarovnávajú do intervalu $[-\pi,\pi]$, čím sa bráni ich nekončenému pretáčaniu.
\end{itemize}

\subsubsection{Pseudokód pre Jakobián}
Nižšie je uvedený pseudo program na výpočet Jakobiho matice, ktorý zohľadňuje všetky články manipulátora a ich vzájomné transformácie.
Tento pseudo program nám umožní vypočítať Jakobián polohy efektora vzhľadom na kĺbové premenné.

\begin{lstlisting}[caption={Výpočet Jakobiho matice}, language=C]
function jacobian(theta[], R[], dR[])
    n = size(theta[]);
    jacob_mat = 3 x n;
    matica = I_3x3;
    pom_vekt = T[n];
    
    for(i = n-1; i > 0; i--)
    begin
        matica = R[i](theta[i]) * matica;
    end
    
    for(j = n; j > 0; j--)
    begin
        vekt = T[n];
        if(n > j)
        begin
            matica = matica * R[j](theta[j]) * transpose();
            pom_vekt = T[j] + R[j+1](theta[j+1]) * pom_vekt;
            vekt = pom_vekt;
        end
        
        vekt = matica + dR[j](theta[j]) * vekt;
        jacob_mat.col(j) = vekt;
    end
    
    return jacob_mat;
end function
\end{lstlisting}

\subsubsection{Pseudokód pre výpočet Jakobiánu orientácie}
Nižšie je uvedený pseudo program na výpočet derivácií rotačných matíc, ktorý zohľadňuje všetky články manipulátora a ich vzájomné transformácie.
\begin{lstlisting}[caption={Výpočet derivácií rotačných matíc}, language=C]
function derRotMat(theta[], dR[], R[])
    n = size(theta[]);
    mat_all(n);
    f_mat = I_3x3;
    b_mat = f_mat;
    
    for(i = n-1; i > 0; i--)
    begin
        f_mat = R[i](theta[i]) * matica;
    end
    
    for(j = n; j > 0; j--)
    begin
        if(n > j)
        begin
            b_mat = R[j+1](theta[j+1]) * b_mat;
            f_mat = f_mat * R[j](theta[j]).transpose();
        end
        mat_all(j) = f_mat * dR[j](theta[j]) * b_mat;
    end
    
    return mat_all;
end function
\end{lstlisting}

\subsubsection{Pseudokód pre inverznú kinematiku}
Nižšie je uvedený pseudo program na iteratívny výpočet inverznej kinematiky pomocou Newtonovej metódy, ktorý zohľadňuje všetky články manipulátora a ich vzájomné transformácie.

\begin{lstlisting}[caption={Iteratívny výpočet inverznej kinematiky}, language=C]
function solveIK(pr, Rr, theta, tol_pos, tol_ori, max_iter)
    for(i=0; i < max_iter; i++)
    begin
        [p0, R0] = forwardKinematics(theta, R);
        (3,3) rp = p0 - Pr;
        (3,3) E = R0 + Rr.transpose();
        ro(0,0) = E(1,0);                         // (010) * E(100)^T
        ro(1,0) = E(2,0);                         // (001) * E(100)^T
        ro(2,0) = E(2,1);                         // (001) * E(010)^T
        
        if(rp.norm < tol_pos && ro.norm < tol_ori)
        begin
            return 1;                              // úspešne max_iterov
        end
        
        J_p = jakobian(theta, R, dR);
        der_R = derRotMat(theta, dR, R);
        J.block<3,6>(0,0) = J_p.block<3,6>(0,0);

        for(j=0; j < DOF; ++j)
        begin
        (3,3) dE_j = der_R[j] * Rr.transpose();

        J(3,j) = dE_j(1,0);
        J(4,j) = dE_j(2,0);
        J(5,j) = dE_j(2,1);
        end
        
        for(k=0; k < DOF; ++k)
        begin
            J(k,k) += lambda;
        end

        minus_r.block<3,1>(0,0) = -rp;
        minus_r.block<3,1>(3,0) = -ro;
        delta_theta = vyries_sustavu_6x6(J, minus_r);
        theta = theta + delta_theta; 
    end
    return false;   
end function
\end{lstlisting}

\textbf{Podmienky ukončenia a robustnosť}

Iterácie sa ukončia pri splnení oboch podmienok:
\begin{itemize}
	\item polohová chyba je menšia ako zadaná tolerancia,
	\item orientačná chyba je menšia ako zadaná tolerancia.
\end{itemize}

Ak sa riešenie nenájde v definovanom maximálnom počte iterácií, stav sa vyhodnotí ako nekonvergentný. Tento mechanizmus chráni systém pred nekonečnou iteráciou pri nedosiahnuteľných cieľoch.

\textbf{Prevádzka v reálnom čase}

IK beží v periodickej riadiacej slučke. Táto slučka neustále prijíma požadovanú pozíciu, prepočítava ju na nové uhly, overuje fyzické limity pohonov a až po ich validácii odošle dáta do servopohonov. Tým je zaistený plynulý a bezpečný pohyb ramena.
