\doxysubsection{Detailed Description}
Hardware interface for servo motor control via PCA9685 PWM driver. 

Implements the Joint\+Actuators interface to convert computed joint angles into PWM control signals for servo motors. Handles\+:
\begin{DoxyItemize}
\item Joint angle to PWM conversion with calibration parameters
\item Servo frequency initialization and PWM channel configuration
\item Joint angle limit enforcement to prevent hardware damage
\end{DoxyItemize}

Each joint requires\+:
\begin{DoxyItemize}
\item Minimum and maximum angle constraints
\item Calibration gain and offset factors
\end{DoxyItemize}

Works with STM32 and I2\+C-\/based PCA9685 16-\/channel PWM expander for simultaneous multi-\/servo control with precise timing.

\begin{DoxyEnumerate}

\item If violated\+: abort and return false (fail-\/safe behavior)
\item If valid\+: convert to degrees\+: deg\+\_\+i = (angles\mbox{[}i\mbox{]} -\/ offset\+\_\+i) \texorpdfstring{$\ast$}{*} gain\+\_\+i \texorpdfstring{$\ast$}{*} $180/\pi$

\item Write PWM value to PCA9685 channel i
\end{DoxyEnumerate}
