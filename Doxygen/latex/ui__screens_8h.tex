\doxysubsection{Detailed Description}
User interface display functions for LCD output. 

Provides inline utility functions for rendering robot arm state information on a 16×2 character LCD display via I2C connection (Liquid\+Crystal\+\_\+\+I2C).

Functions display\+:
\begin{DoxyItemize}
\item End-\/effector position (X, Y, Z Cartesian coordinates)
\item End-\/effector orientation (Roll-\/\+Pitch-\/\+Yaw Euler angles)
\end{DoxyItemize}

All values are formatted to 1 decimal place for readability on small displays.
